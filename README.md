# V-Drop — Creator & Social Platform

A full-stack social creator platform built with Flutter and a custom Node.js + PostgreSQL backend, 
featuring real-time chat, geo-based content drops, stories, post feed, and Instagram/YouTube integrations across 22 screens.

> ⚠️ **Note:** The live backend is currently unavailable as the free PostgreSQL instance on Render 
> has expired. Please watch the demo video below to see the app in action.

## 🚀 Features

- 22 screens — onboarding, post feed, stories, likes/comments, notifications
- Real-time chat with custom Node.js backend
- Geo-based content drops using OpenStreetMap API
- Instagram & YouTube integrations with follower analytics
- Creator, Professional, and Business account types
- Social graph — follow/unfollow system
- Push notifications & full authentication
- Shipped as signed APK on Android 8+

## 🛠️ Tech Stack

- **Frontend:** Flutter, Dart, Provider
- **Backend:** Node.js, PostgreSQL
- **APIs:** OpenStreetMap, Instagram API, YouTube API
- **Tools:** Git, GitHub, Figma, Android Studio
